# 🎓 Student Management System (C++)

## 📌 Overview

This is a console-based Student Management System developed using C++.
It allows efficient management of student records using file handling.

## 🚀 Features

* Add new student records
* Display all students in tabular format
* Update existing student details
* Delete student records
* Search student by roll number
* View class statistics (average, top performer, pass %)
* Input validation for accurate data entry

## 🛠️ Technologies Used

* C++
* File Handling (Binary Files)
* Object-Oriented Programming (OOP)

## 💡 Key Concepts Used

* Classes and Objects
* File Streams (`ifstream`, `ofstream`, `fstream`)
* Data Validation
* Menu-driven program design

## ▶️ How to Run

### Using VS Code:

1. Install C++ compiler (MinGW)
2. Open project folder
3. Compile:
   g++ main.cpp -o sms
4. Run:
   ./sms


## 📊 Sample Features

* Automatic grade calculation (A–F)
* Duplicate roll number prevention
* Corruption check for data file
* Clean tabular display using `iomanip`
